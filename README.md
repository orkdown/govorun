# 🎙️ Silero TTS Discord Bridge (Desktop + Web + Telegram)

Локальный, бесплатный и автономный Text-to-Speech (TTS) мост для Windows на базе нейросети **Silero TTS** (`v4_ru`). Позволяет передавать высококачественную русскую речь напрямую в микрофон **Discord** через виртуальный аудиокабель (`VB-Audio Virtual Cable`), управляя текстом через веб-пульт на ПК, браузер смартфона по локальной сети или через Telegram-бота.

Голоса и качество идентичны официальному боту Silero: **@silero_voice_bot**.

---

## 🌟 Возможности проекта

1. **Нейросеть Silero TTS (v4_ru, 48000 Hz):**
   - 6 голосов: `aidar` (Айдар), `eugene` (Евгений), `xenia` (Ксения), `baya` (Байя), `kseniya` (Ксения 2), `random` (Случайный).
   - Автоматическая расстановка ударений (`put_accent=True`) и буквы «Ё» (`put_yo=True`).
   - Ручные ударения через `+` перед гласной (`з+амок` vs `зам+ок`).
   - Автоматическая нормализация чисел (`num2words`) и перевод английского сленга в русский транслит.
   - Предпрогрев модели на старте: мгновенный отклик генерации (<300 мс на CPU).

2. **Быстрые звуковые эффекты (DSP / 0% нагрузки на CPU):**
   - ✨ **Обычный** — чистый студийный нейро-голос.
   - 📻 **Рация** — военная рация (walkie-talkie) со срезкой частот и лёгким овердрайвом.
   - 🐿️ **Бурундук / Гном** — повышенный питч (+5 полутонов), мультяшный голос.
   - 👹 **Демон / Монстр** — пониженный питч (-5 полутонов) с глубоким саб-басом.
   - 🤖 **Робот** — кибернетическая кольцевая модуляция звука.
   - 📢 **Эхо / Арена** — объемное пространственное отражение.

3. **Прямая маршрутизация звука без временных файлов:**
   - Вывод напрямую из оперативной памяти (`numpy` массив) через `sounddevice` в `CABLE Input (VB-Audio Virtual Cable)`.
   - Режим **мониторинга (Audio Monitoring)**: возможность одновременно слышать свой же сгенерированный голос в наушниках, чтобы контролировать речь.
   - Регулировка громкости синтеза (от 20% до 200%).

3. **Потокобезопасная очередь (TTS Queue):**
   - Исключает наложение звука и сбои при быстрой отправке нескольких сообщений подряд из разных источников (веб + Telegram).

4. **Интерактивный Dark Mode Web-пульт (SPA):**
   - Современный Discord-стиль, адаптивный дизайн для ПК и смартфонов.
   - Отправка текста по клавише `Enter` (без Shift).
   - Интерактивный **Саундборд быстрых фраз** с возможностью добавления и удаления собственных шаблонов на лету.
   - Модальное окно настроек Telegram прямо в интерфейсе (без необходимости редактировать конфигурационные файлы).
   - Индикатор статуса ("Готов", "Озвучивание...", размер очереди).

5. **Telegram Бот (aiogram 3.x):**
   - Работает в едином асинхронном цикле с сервером FastAPI.
   - Поддерживает горячее переподключение токена из веб-панели без перезапуска программы.
   - Фильтрация по `tg_user_id` (защита от посторонних).
   - Команды: `/start`, `/voice` (инлайн-кнопки переключения голосов), `/status`.
   - Поддержка мгновенной смены голоса прямо в сообщении: `[eugene] Здорово парни`.

## 🚀 Быстрый старт

### Шаг 1. Установка виртуального кабеля (VB-CABLE)
Если у вас ещё не установлен виртуальный аудиокабель:
- В папке проекта `vb/` уже находятся установочные файлы драйвера: запустите **`vb/VBCABLE_Setup_x64.exe`** от имени Администратора и нажмите **Install Driver**.
- При необходимости перезагрузите компьютер.

### Шаг 2. Настройка Discord
1. Откройте **Discord** -> **Настройки пользователя** -> вкладка **Голос и видео**.
2. В поле **Устройство ввода** (Input Device) выберите:
   `CABLE Output (VB-Audio Virtual Cable)`
3. В поле **Устройство вывода** (Output Device) оставьте ваши обычные наушники/динамики.
4. Рекомендуется отключить в Discord: *Шумоподавление (Noise Suppression)*, *Эхоподавление* и поставить режим ввода *Активация по голосу* с низкой чувствительностью или *Режим рации*.

### Шаг 3. Запуск моста
Просто запустите файл **`start.bat`**.

Скрипт автоматически:
- Создаст изолированное виртуальное окружение `venv` (если его нет).
- Установит все необходимые библиотеки из `requirements.txt` (PyTorch, sounddevice, FastAPI, aiogram, omegaconf и др.).
- Автоматически найдет устройство `CABLE Input`.
- Загрузит модель Silero TTS и запустит веб-пульт.

## 🖥️ Использование веб-пульта

После запуска откройте в браузере:
- **На компьютере:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Со смартфона (по домашнему Wi-Fi):** `http://<IP-вашего-ПК>:8000` (точный адрес отображается в консоли и в меню 📱 на пульте).

В веб-пульте доступно:
- **Выбор голоса:** переключение в 1 клик.
- **Поле ввода:** пишите текст и жмите `Enter`.
- **Быстрые фразы:** кликайте по кнопкам для мгновенного ответа в голосовой чат, добавляйте свои фразы через кнопку `+ Добавить`.
- **Аудиоустройства:** выбор основного устройства кабеля и переключатель мониторинга в наушники.
- **Шестеренка (⚙️):** ввод Telegram Bot Token и User ID.

Токен бота уже сохранен в файле конфигурации:
- **Имя бота:** `@orkdownbot` (https://t.me/orkdownbot)

2. Бот покажет ваш цифровой **Telegram ID** и меню выбора голосов.
3. Если хотите ограничить доступ, чтобы никто другой не мог писать вашему боту: укажите полученный ID в веб-пульте в окне настроек (⚙️) или в `config.json` в поле `"tg_user_id"`.
4. Любой текст, отправленный боту, автоматически преобразуется (числа прописью, английский сленг в транслит) и мгновенно звучит в Discord!

## 🐧 Развёртывание на VPS (Ubuntu 24.04)

Сервер можно запустить на любом VPS без звуковой карты и без домена/сертификатов (доступ напрямую по `http://IP-СЕРВЕРА:8000`).

### 1. Клонирование и установка в 1 команду
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> voicer
cd voicer
chmod +x setup_ubuntu.sh
./setup_ubuntu.sh
```

Скрипт автоматически:
- Установит системные зависимости (`ffmpeg`, `python3-venv`, `libopus0` и др.).
- Установит лёгкую CPU-версию `torch` и все пакеты из `requirements.txt`.
- Создаст `config.json` и настроит фоновую службу **systemd** (`voicer.service`).

### 2. Настройка токенов
Отредактируйте `config.json`, вписав токен Discord-бота и/или Telegram:
```bash
nano config.json
```

### 3. Управление службой
```bash
# Запуск
sudo systemctl start voicer

# Проверка статуса
sudo systemctl status voicer

# Просмотр логов в реальном времени
sudo journalctl -u voicer -f

# Перезапуск
sudo systemctl restart voicer
```

Веб-панель будет доступна в браузере по адресу:
`http://IP_ВАШЕГО_СЕРВЕРА:8000`

## 🛠️ Возможные проблемы и их решения

- **Ошибка: `ModuleNotFoundError: No module named 'omegaconf'`**
  - Решена: пакет `omegaconf>=2.0.0` включен в `requirements.txt`.
- **Вопрос о доверии к репозиторию PyTorch Hub (`trust_repo`)**:
  - Решена: в `app.py` передан параметр `trust_repo=True`, подтверждение в консоли больше не требуется.
- **В Discord не слышно речь**:
  - Убедитесь, что в Discord в качестве устройства ввода выбран `CABLE Output (VB-Audio Virtual Cable)`.
  - Убедитесь, что в веб-пульте выбран `CABLE Input (VB-Audio Virtual Cable)`.
  - Включите переключатель «Мониторинг в наушники» в веб-пульте, чтобы убедиться, что синтез воспроизводится.
